# Klavye ve Fare Kısayolları

Programda: **Yardım → Klavye kısayolları**. Tek tuşlu kısayollar (R, Del, S, L, T, D, J, F, ok tuşları)
yalnızca çizim alanı etkinken çalışır; özellik panelinde yazı yazarken tetiklenmez.

## Dosya

| Kısayol | İşlem |
|---|---|
| Ctrl+N | Yeni proje |
| Ctrl+O | Proje aç |
| Ctrl+S | Kaydet |
| Ctrl+Shift+S | Farklı kaydet |
| Ctrl+P | Tüm projeyi PDF'e aktar |
| F1 | Kullanım kılavuzu |

## Düzen

| Kısayol | İşlem |
|---|---|
| Ctrl+Z / Ctrl+Y | Geri al / İleri al |
| Ctrl+X / Ctrl+C / Ctrl+V | Kes / Kopyala / Yapıştır |
| Ctrl+A | Tümünü seç |
| Del | Seçimi sil |
| R | Seçimi 90° döndür; yerleştirme aracındayken önizlemeyi döndür |
| ← → ↑ ↓ | Seçimi bir grid adımı (5 mm) kaydır |
| Shift + ok tuşları | Seçimi 1 mm kaydır |

## Araçlar

| Kısayol | Araç |
|---|---|
| S | Seç |
| L | Çizgi |
| T | Metin |
| D | Dirsek (90° bağlantı noktası) |
| J | T bağlantı |
| Esc | İşlemi iptal et, seçim aracına dön |

## Görünüm ve sayfa

| Kısayol | İşlem |
|---|---|
| Fare tekerleği | İmlecin olduğu noktaya yakınlaştır / uzaklaştır |
| Orta tuş + sürükle | Kaydır (pan) |
| F | Sayfaya sığdır |
| Ctrl+Num+ / Ctrl+Num− | Yakınlaştır / Uzaklaştır |
| PgUp / PgDn | Önceki / sonraki sayfa |

## Fare

| İşlem | Sonuç |
|---|---|
| Tık | Nesne seç |
| Ctrl + tık | Seçime ekle / çıkar |
| Boş alanda sürükle | Alan seçimi (tamamen içinde kalanlar) |
| Seçili nesneyi sürükle | Taşı (referans noktası grid'e oturur) |
| Sağ tık (Seç aracında) | Bağlam menüsü: kes, kopyala, yapıştır, sil, döndür |
| Sağ tık (diğer araçlarda) | İptal, seçim aracına dön |
